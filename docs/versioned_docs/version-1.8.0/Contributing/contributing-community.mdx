There are several ways you can interact with the EarthMind community and learn more about the EarthMind codebase.

## Join the EarthMind Discord server

Join the [EarthMind Discord Server](https://discord.gg/EqksyE2EX9) to ask questions and showcase your projects.

## Follow EarthMind on X

Follow [@earthmind_ai](https://twitter.com/earthmind_ai) on X to get the latest news about EarthMind.

## Star EarthMind on GitHub

If you like EarthMind, you can star the [EarthMind GitHub repository](https://github.com/earthmind-ai/earthmind).
Stars help other users find EarthMind more easily, and quickly understand that other users have found it useful.

Because EarthMind is open-source, the more visible the repository is, the more likely the codebase is to attract [contributors](/contributing-how-to-contribute).

## Watch the GitHub repository

You can watch the [EarthMind GitHub repository](https://github.com/earthmind-ai/earthmind) to get notified about new releases and other repository activity.

To get release notifications only, select **Releases only**.

If you select **Watching**, you will receive notifications about new releases as well as issues, discussions, and pull requests, if you are interested in that activity.
For information about customizing repository notifications, see the [GitHub documentation on repository subscriptions](https://docs.github.com/en/account-and-profile/managing-subscriptions-and-notifications-on-github/managing-subscriptions-for-activity-on-github/viewing-your-subscriptions).

## Request enhancements and get help through GitHub

You can also submit feature requests and get help with EarthMind through the GitHub repository.
For more information, see [Get help and request enhancements](/contributing-github-issues).
