This guide explains how to deploy EarthMind on [Hugging Face Spaces](https://huggingface.co/spaces/).

1. Go to the [EarthMind Space](https://huggingface.co/spaces/EarthMind/EarthMind?duplicate=true).
2. Click **Duplicate Space**.
3. Configure the duplicated Space:

   1. Enter a name for your Space.
   2. Select either public or private visibility.
   3. Click **Duplicate Space**.

   ![Hugging Face deployment dialog](/img/hugging-face-deployment.png)

When setup is complete, you're redirected to your new Space automatically, and your EarthMind instance is ready to use.
