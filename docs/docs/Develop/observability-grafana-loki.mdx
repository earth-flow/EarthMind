Terraflow can emit structured JSON logs for ingestion by [Grafana Loki](https://grafana.com/oss/loki/).

This page demonstrates how to connect Terraflow to the [reference Grafana stack](https://github.com/terraflow-ai/terraflow/tree/main/deploy/observability/grafana-loki) shipped with the Terraflow repository.
For more information, see the [README](https://github.com/terraflow-ai/terraflow/tree/main/deploy/observability/grafana-loki).

To consume structured Terraflow logs with other ingestion providers, see [Logs](/logging).

## Prerequisites

- [Clone the Terraflow repository](/contributing-how-to-contribute#install-terraflow-from-source) to access the [reference Grafana stack](https://github.com/terraflow-ai/terraflow/tree/main/deploy/observability/grafana-loki). If you are using your own Grafana and Loki instances, cloning the repository is not required.
- [Docker and Docker Compose](https://docs.docker.com/)

## Configure environment variables

1. In the root folder of your Terraflow application, edit your existing `.env` file or create a new one.
2. Add the following environment variables. Replace the placeholders with the values for your deployment:

   ```text
   TERRAFLOW_LOG_ENV=container
   TERRAFLOW_LOG_LEVEL=INFO
   TERRAFLOW_LOG_FILE=/var/log/terraflow/terraflow.log
   TERRAFLOW_SERVICE_NAME=terraflow
   TERRAFLOW_VERSION=1.10.0
   TERRAFLOW_ENVIRONMENT=production
   ```

   Setting `TERRAFLOW_LOG_ENV=container` switches structlog's terminal processor to [`JSONRenderer`](https://www.structlog.org/en/stable/api.html#structlog.processors.JSONRenderer), so every line written to stdout is a JSON object containing the event message, level, timestamp, logger name, exception structure, and service metadata. For more information, see [Logs](/logging).

   The shipped Promtail configuration scrapes `*.log` files from a directory rather than stdout. `TERRAFLOW_LOG_FILE` must point at a file inside the directory that Promtail watches. Set `TERRAFLOW_LOG_DIR` to that same directory so Terraflow creates the file in the right place.

3. Start the reference Loki + Promtail + Grafana stack from the repository:

   ```bash
   cd deploy/observability/grafana-loki
   export TERRAFLOW_LOG_DIR=/var/log/terraflow
   docker compose up -d
   ```

4. Launch Terraflow with your `.env` file:

   ```bash
   uv run terraflow run --env-file .env
   ```

5. Run a flow in Terraflow to generate log traffic.

6. Open Grafana at `http://localhost:3000` and navigate to **Dashboards** > **Terraflow Logs** to view structured log output, including panels for structured tracebacks, PII redaction, stdlib library output, and service/environment/version coverage.
