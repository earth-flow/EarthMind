Connect coding agents such as **Bob (IBM)** and **Claude Code** to a Terraflow instance so they can build and run flows over MCP.

This page describes the <Icon name="Terminal" aria-hidden="true"/> **Terraflow MCP Client** entry in **Settings**. It is different from Terraflow's other MCP options.

* [**Use Terraflow as an MCP client**](/mcp-client): Use the **MCP Tools** component in flows so agent components _on the canvas_ can call external MCP servers or Terraflow MCP URLs.
* [**Use Terraflow as an MCP server**](/mcp-server): Use the **MCP Servers** page in Terraflow to expose your Terraflow project as an MCP server to desktop clients such as Cursor or Windsurf.

## Connect Bob (IBM) or Claude Code

To connect Terraflow to a coding agent, do the following:

1. Click your profile icon, select **Settings**, and then click <Icon name="Terminal" aria-hidden="true"/> **Terraflow MCP Client**.
2. Select the coding agent you want to connect to Terraflow, and follow the steps shown in the UI.

    All client configurations run `lfx-mcp` with `uvx`, and set `TERRAFLOW_SERVER_URL` to your Terraflow server URL and `TERRAFLOW_API_KEY` to a Terraflow API key of your choice.

    * To connect to **Bob (IBM)**, paste the configuration JSON into `~/.bob/settings/mcp_settings.json`, or use **Edit Project MCP** for a project-only setup.
    * To connect to **Claude Code**, run the `claude mcp add` command shown on the page, or manually add the JSON configuration to `~/.claude.json`.

    If you do not set `TERRAFLOW_API_KEY`, the coding agent can log in with the Terraflow username and password you use to sign in to the Terraflow web UI for that server.
